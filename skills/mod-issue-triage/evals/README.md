# mod-issue-triage 验收案例（第一版）

本目录用于放置本 Skill 的 10 个验收案例，目前仅保留说明，暂不包含实际案例文件、可执行脚本或测试运行器。

计划中的 10 个案例：

1. 信息完整
2. 信息极少
3. 只有日志
4. 描述矛盾
5. 单人正常、多人异常
6. 无复现步骤
7. 要求直接修 Bug
8. 非 Minecraft 游戏
9. 版本信息不完整
10. 信息混杂

第一版的验收方式：由人工对照 `SKILL.md` 中的验收标准逐项检查，重点确认是否编造事实、7 个字段是否齐全、矛盾是否被标记、越界请求是否说明边界、推测是否带标注。

暂不实现自动评估，也不包含任何可运行代码；后续版本再考虑把上述案例转为自动化用例。
